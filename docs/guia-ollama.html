Tu asistente, en tu equipo.

El análisis de Excel y las descargas PDF/JSON funcionan sin Ollama. Para priorizar el resumen con un modelo local, instala Ollama en la computadora donde abres esta página.

1. Instala Ollama y descarga el modelo

Descarga el instalador desde ollama.com. En una terminal ejecuta:

ollama pull qwen3:4b

El modelo ocupa aproximadamente 2,5 GB; el uso de memoria durante la ejecución es mayor. El tiempo de respuesta depende de tu equipo.

2. Autoriza únicamente esta página

Cierra Ollama desde su icono junto al reloj. En PowerShell, inicia una instancia accesible sólo desde tu equipo con el origen de esta página autorizado:

$env:OLLAMA_HOST = "127.0.0.1:11434"
$env:OLLAMA_ORIGINS = "https://luisfer6.github.io"
$env:OLLAMA_NO_CLOUD = "1"
ollama serve

Mantén esa terminal abierta. No necesitas abrir puertos del router ni utilizar comodines en OLLAMA_ORIGINS. La autorización permite que esta página solicite respuestas a tu instalación local.

3. Conecta desde el informe

Carga tu Excel y abre «Informe técnico». Pulsa «Conectar Ollama en este equipo» y, si el navegador lo solicita, permite a esta página acceder a la red local. Después pulsa «Priorizar con Ollama».

Qué información utiliza

El modelo recibe únicamente el ID de cada hallazgo, su regla, criticidad y cantidad de evidencias. Se valida que devuelva entre uno y cinco IDs existentes, sin duplicados. El resumen conserva frases sustentadas por evidencia; la IA no confirma incidentes ni modifica la criticidad.

Si no conecta

Comprueba que Ollama esté iniciado, que el modelo aparezca en ollama list y que el origen autorizado coincida exactamente con la dirección de esta página. Algunos navegadores o políticas de empresa bloquean conexiones de una página HTTPS a servicios locales. En ese caso, puedes seguir usando el análisis y el informe sin Ollama, o utilizar la edición local de SOC Lens.

El Excel y el caso se conservan sólo en la memoria de esta pestaña. Al recargarla o cerrarla se pierden. Descarga tus entregables antes de salir. La primera carga del motor utiliza Pyodide desde jsDelivr y paquetes de PyPI; esos servicios reciben solicitudes de descarga, no el contenido del Excel.
